# 디자인 가이드 — 골라줘 v2 (UI 프로토타입)

> 번호 · 위젯명 · 비즈니스 명칭 · P번호는 각 화면 파일 맨 위 대응표 주석, 줄 끝 `// A-5 P07` 주석과 **같다**.

## 1. 화면 흐름

```
A 무슨 결정? (+ 결정 지갑) ──쌓기(push)──▶ B 상세 [지금 기분 · 옆으로(tab): 옵션 | 결정 방식] ──덮기(modal)──▶ C 결과(임의)
   탭 1: 상황 카드              탭 2: 골라줘!                                     탭 3: 결정 잠금
```
- 쌓기 = `Navigator.push`/`pop` · 옆으로 = `TabBar` · 덮기 = `showModalBottomSheet`
- 화면은 A · B · C 3개뿐. 기획에 없는 화면은 만들지 않는다.
- 결정 과정 4단계 **FEEL → FIGHT → REVEAL → LOCK**를 화면에 대응: FEEL = B-2, FIGHT = B-6, REVEAL = C-3 · C-4, LOCK = C-7

## 4. 비주얼 — "iOS처럼 조용하게, 화면마다 주인공은 하나"

- **원칙:** 한 화면에 시각적 주인공은 하나(A = "무슨 결정?", B = 「골라줘!」 버튼, C = 결과 이름). 나머지는 iOS 시스템 회색으로 물러난다.
- **강조색은 코랄 하나** `#FF5A36`(글자 `#C63A1A`, 옅은 바탕 `#FFF0EA`) — 추천 칩 · 주 버튼 · 선택 테두리 · 진행 막대 · ❤️에만.
- **토큰 (`Tok`, `lib/widgets.dart`)** — iOS 시스템 색을 따른다: 바탕 `#F2F2F7`(grouped background) · 카드 `#FFFFFF` · 글자 `#1C1C1E` / `#3A3A3C` / `#8E8E93` · 구분선 `#E5E5EA` · 꺾쇠 `#C7C7CC`
- **카드:** 테두리 없는 흰 그룹 카드, 둥근 18, 그림자 없음 (선택 시만 코랄 2px). **시트:** 위 모서리 24 + 회색 손잡이.
- **아이콘 · 전환:** CupertinoIcons(꺾쇠 › · 하트 · 체크 원) · 모든 플랫폼에서 iOS식 오른쪽 밀기 화면 전환 · 떠 있는 알약 SnackBar
- **카테고리 색은 칩 앞 7px 점에만** — 8가지 색이 화면을 어지럽히지 않게.
- **글자:** 36(결과) / 34(A 큰 제목, iOS Large Title) / 22(B 제목) / 17 / 16(카드 제목) / 15 / 13.5 / 12.5(보조) / 12 / 10.5(단계). 굵기 800 · 700 · 600. 큰 글자는 자간 −0.4 ~ −0.9.
- **버튼:** 알약(Capsule) 높이 52~58, 주 버튼은 화면당 1개.
- **간격:** 화면 좌우 20(폰) / 32(넓은 화면) · 카드 사이 10~14 · 카드 안 14~16.
