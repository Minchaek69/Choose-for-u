형식: 쟁점 → 내 주장 → 반론(AI · 나) → 재반론/수정 → 결론(유지 · 수정 · 폐기) → 근거 P번호 · 리뷰 # → 전 · 후

## 쟁점 1 (대표) — 「다시」를 몇 번까지 허용할까
- **내 주장:** 「다시」는 무제한. 사용자가 원할 때까지 돌릴 자유가 있어야 한다(P03).
- **반론 (AI):** "무제한 다시는 현행 앱의 문제(리뷰 유형 ③, 저니 5단계)를 그대로 복사한다. 선택장애 사용자에게 무한 재시도는 자유가 아니라 함정이다 — P05 오류 예방 위반."
- **반론 (나):** 횟수를 막으면 하루 횟수를 기억해야 해서 영구 저장이 필요하다 → 감점.
- **재반론 / 수정:** 막지 않고 *말린다*. 3번째 결과부터 STOP 배너("넌 결정 문제가 아니라 허락이 필요한 거야"), 결정 잠금을 누르면 「다시」 비활성(잠금 해제로 되돌릴 수 있음 → P03 유지).
- **결론:** **수정**
- **근거:** P05 · P03 · 리뷰 #2(유형 ③)
- **전 · 후:** 전 = `docs/screenshots/before_C_v2draft.png` (처음 만든 시안: 「다시」 버튼만 있는 C) → 후 = `07_C_stop.png` (C-8 STOP 배너 + C-7 잠금 시 다시 비활성)

## 쟁점 2 — FEEL(지금 기분)을 어디에 둘까
- **내 주장:** 앱 첫 화면 앞에 "지금 기분은?" 화면을 따로 둔다 (FEEL → FILTER → FIGHT 순서 그대로).
- **반론 (AI):** "화면이 4개가 되어 기획 3화면 규칙 위반(감점), 탭 수도 1 늘어 P07 효율 위반."
- **재반론 / 수정:** 별도 화면 대신 B 상단 ChoiceChip 3개(B-2). 기본값 😐 그냥이라 안 눌러도 된다.
- **결론:** **수정** · **근거:** P07 · P08 · 안내문 5장(기획에 없는 화면)
- **전 · 후:** 전 = 기분 화면 스케치 → 후 = B-2 칩 한 줄

## 쟁점 3 — 결과가 preset인데 "후회 테스트"를 넣어도 될까
- **내 주장:** C에서 "살짝 아쉬웠어?"를 묻는다. 결과를 보고 생기는 감정이 진짜 선호를 드러낸다(가짜 랜덤 · Regret Test).
- **반론 (AI):** "결과가 미리 정한 값인데 '네 진짜 답'을 말하면 사용자를 속이는 것 아닌가? P10 도움말 · 정직성."
- **재반론:** 테스트는 결과를 *바꾸지 않고* 사용자의 반응만 되돌려 준다. 그리고 C-9에 "예시 결과(실제 추천 로직 없음)"를 항상 표시한다.
- **결론:** **유지** · **근거:** P06 · P10
- **전 · 후:** 유지 — 최종 C 화면

## 쟁점 4 — 결정 잠금을 24시간 저장할까
- **내 주장:** 잠근 결정을 24시간 보관해 "오늘은 다시 보지 않기"를 강제.
- **반론 (AI · 나):** 영구 저장(shared_preferences 등)은 안내문 5장 감점.
- **결론:** **폐기** — 잠금은 시트가 열린 동안만 보여 주고, 저장은 `// STATE: S3` 주석으로 v3 상태관리 수업에 넘긴다.
- **근거:** 안내문 5장 · AGENTS.md MUST NOT

## 쟁점 5 — 게임 방식을 실제로 돌릴까
- **내 주장:** 듀얼 · 토너먼트를 진짜로 진행시켜야 "게임"이다.
- **반론 (AI):** "실제 대진·랜덤은 안내문 5장 '실제 계산·추천 알고리즘' 감점. 소개만 있으면 빈약하다."
- **재반론 / 수정:** 게임 카드에 db.json의 상황별 **추천 배지**(B-6)를 붙이고, 결과에 그 게임 이름으로 "결승 A 🆚 B"(C-3)를 보여 줘 흐름을 체감하게 한다. 실제 대진은 v3.
- **결론:** **수정** · **근거:** P07 · P02 · P10(B-7 안내)

## 쟁점 6 — 결정 방식을 몇 개 보여 줄까 (스스로 찾은 반론)
- **내 주장:** 듀얼부터 가위바위보까지 12가지를 모두 보여 줘야 "놀 거리"가 많다.
- **반론 (나):** "선택장애 사용자에게 방법을 12개 고르게 하면 앱이 또 하나의 선택 문제가 된다." (P08 미니멀 · P07)

- **결론:** **수정** · **근거:** P08 · P07 · 전 = 12개 나열 / 후 = `docs/screenshots/03_B_games.png`
